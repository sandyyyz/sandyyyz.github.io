590b87b109a8 · [PATCH 0/2] mm: avoid redundant reads of the vm_refcnt cacheline in anonymous faults ​

Seunghyun An (san55@wisc.edu)｜linux-mm｜内存管理

该系列补丁旨在消除匿名缺页路径上对 vm_refcnt cacheline 的冗余读取。在 per-VMA-lock 缺页路径中，vma_start_read()/vma_end_read() 已使该缓存行在 CPU 间迁移，而 __folio_set_anon() 读取 __vm_anon_pgoff_hi 以及 __vmf_anon_prepare() -> vma_has_anon_rmap() 中的 vma_is_attached() 和 vma_assert_stabilised() 又额外加载了同一缓存行。

学习价值：系统性地剖析了缺页热路径上的缓存行争用来源，对理解 per-VMA lock 与性能优化方法论很有帮助。

39fdc7c0337b · [PATCH v1] mm/rmap: fix migration entries being treated as partial unmaps ​

Joanne Koong (joannelkoong@gmail.com)｜linux-mm｜内存管理

该补丁修复 try_to_migrate_one() 在迁移大匿名 folio 时，migration entries 被误判为部分解除映射的问题。逐个替换 PTE 为 migration entry 的过程中，__folio_remove_rmap() 看到不再完全映射的 folio 便调用 deferred_split_folio()，错误地将其标记为 PG_partially_mapped 并放入延迟分裂队列，而实际上没有任何页面真正解除映射。

学习价值：深入展示了 migration entries 与 rmap 计数的交互细节，是理解大 folio 迁移与延迟分裂机制的好材料。

9e39e531b6bf · ChaCha AVX-512 Optimization For Linux 7.5 Yields Up To 99% Improvement On AMD Zen 5 ​

Michael Larabel｜phoronix｜其他动态

Linux 内核的 ChaCha 对称流密码代码此前已有 AVX-512 优化路径，但主要针对早期因降频问题而受限的 Intel Skylake 处理器。Linux 7.5 中将针对当前不受降频限制的 Intel 和 AMD 处理器调优，在 AMD Zen 5 上 ChaCha 性能最高提升 99%。

学习价值：是学习内核 crypto 子系统中 SIMD 指令优化（AVX-512）与 CPU 微架构特性如何影响性能的绝佳案例。

33c05c67fe77 · [RFC PATCH 0/2] percpu, local_lock: drop btf_type_tag where no compiler records it ​

Vineet Gupta (vineet.gupta@linux.dev)｜lkml｜其他动态

本系列目标是在 GCC 下启用 PAHOLE_HAS_BTF_TAG（目前仅限 Clang）。尽管 GCC 相关修复（PR128479、PR125991）在推进，x86 defconfig 仍产生约 4 万条 -Wattributes 警告，足以破坏 -Werror 构建；GCC 侧修复请求（PR128480）被拒绝，因此内核选择在无意义的位置移除 btf_type_tag。

学习价值：展示了内核与编译器社区协作解决构建问题的真实过程，对理解 BTF、pahole 与工具链依赖很有价值。

0ca9ff10b6e3 · Linux 7.5 To Convey To User-Space Multi-Grain Timestamp Usage On Files ​

Michael Larabel｜phoronix｜其他动态

Linux 6.13 合入的 multigrain timestamp 支持允许按文件在粗粒度与细粒度时间戳之间切换，最初用于解决 NFS 缓存问题。其局限是用户空间无法得知某文件的时间戳是否为 multi-grain，Linux 7.5 将向用户空间暴露这一信息。

SJ Park (sj@kernel.org)｜linux-mm

Seunghyun An (san55@wisc.edu)｜linux-mm

该补丁修改 linear_anon_page_index()，使其对匿名 VMA 使用 vm_pgoff。自 commit 93c0c8dc87f6 引入 anon pgoff 机制后，__folio_set_anon() 在每次匿名缺页时都会读取 __vm_anon_pgoff_hi，而该字段紧邻 vm_refcnt 所在的 cacheline，多线程在同一 VMA 上缺页时会造成缓存行乒乓，引发额外的缓存一致性传输开销。
