6832e4b9f03f · [RFC PATCH v1 00/11] unwind: Minimal DWARF CFI stack unwinding for x86, arm64, and riscv ​

Ian Rogers (irogers@google.com)｜rust-for-linux｜Rust in Linux

该 RFC 系列引入 Minimal DWARF CFI 栈回溯（stack unwinding）机制，同时覆盖用户态延迟调用链（unwind_user / PERF_RECORD_CALLCHAIN_DEFERRED）和内核态栈跟踪（stacktrace.h / HAVE_RELIABLE_STACKTRACE），支持 x86-64、ARM64 和 RISC-V 三种架构，并附带一个独立的 C 语言构建时 .eh_frame 精简工具（scripts/min_eh_frame.c）。该方案使无论是否编译 frame pointer 的二进制都能可靠回溯，且避免引入重复的 .sframe 段。

学习价值：对理解 perf 调用链采样、DWARF CFI 原理以及跨架构可靠栈回溯的实现非常有价值，是连接 tracing 与二进制格式的优秀学习材料。
