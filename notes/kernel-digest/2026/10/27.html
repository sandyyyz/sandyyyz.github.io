学习价值：展示了大页内核下 scatter-gather 聚合可能违反协议限制的隐蔽 bug，对学习 virtio 规范约束和 free page reporting 机制很有价值。

[PATCH 46/46] fs/proc/task_mmu: refuse addresses beyond 32 bits on 32bit ​

Systemd adds support for components written in Rust ​

jzb｜lwn

Christian Brauner 宣布已合并「允许用 Rust 编写 systemd 叶子组件」的支持。Rust 仅用于新的叶子组件，现有代码不会被移植，其他组件所依赖的部分也不会用 Rust 实现。Brauner 表示项目希望在 systemd 核心中推进 Rust 支持，但 Rust 对动态库的支持仍存在若干阻碍，否则会导致每个二进制文件体积大幅膨胀；若进展顺利，该工作有望出现在 systemd v263 中。

[PATCH v5 10/11] drm/tyr: gem: flush write-combine BOs from probe-time coherence ​

drm/tyr（Rust 编写的 DRM 驱动）修复非一致性设备上的缓存一致性问题：shmem 层通过 cached mapping 零初始化新页，而 tyr 以 write-combine 映射 buffer，在非一致设备上陈旧 cache line 可能覆盖后续 uncached 写入，导致 GPU 或用户空间读到零。修复是在 probe 时读取设备一致性，一致时用 write-back 映射，否则 write-combine，并在 BO_CREATE 时获取 sgtable 使 dma_map_sgtable() 在 uncached 访问前 flush 零初始化页。

学习价值：深入讲解 DMA 缓存一致性、write-combine 映射与 shmem 零初始化交互的陷阱，是学习非一致 SoC 上 GPU 驱动缓存管理的高级案例。

[PATCH v5 02/11] rust: task: add task_size() ​

Ke Sun via B4 Relay (devnull+sunke.kylinos.cn@kernel.org)｜rust-for-linux

[$] Python's experimental JIT to be removed ​

jzb｜lwn｜LWN 订阅文章，仅预览

CPython 在 2024 年为 3.13 引入的实验性 JIT 编译器即将被移除。Python steering council 于 6 月宣布暂停 main 分支上的 JIT 工作，直到有被接受的 PEP 能解决维护性、兼容性问题，并给出明确的成功指标与完成时间表。维护者随后提出 PEP 836（"JIT Go Brrr"）试图满足要求，但经过数月讨论后 JIT 维护者仍决定放弃。

学习价值：虽非内核内容，但它展示了大型开源项目如何用 PEP 流程评估实验性优化特性的维护成本，对理解内核特性合入与淘汰机制有类比价值。
